These are my Python solutions to various algorithmic tasks from Stepik. 
They helped me practice core skills that are directly relevant to bioinformatics: working with sequences, matrices, dictionaries, and file handling.

- `f_of_x.py` — basic function implementation and math operations.
- `find_indices.py` — searching and indexing in lists.
- `matrix-neighbor-sum.py` — matrix operations and neighbor analysis.
- `modify_even_numbers.py` — list transformations and conditional logic.
- `number_sequence.py` — generating sequences and patterns.
- `update_dictionary.py` — dictionary manipulation.
- `word_frequency_counter.py` — counting frequencies.

- `text_decompressor.py` — reads `dataset_3363_2.txt`, restores the string, writes result to `output.txt`.
